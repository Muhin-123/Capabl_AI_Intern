# Academic AI Agent

## About

Academic AI Agent is an AI-based application that helps students ask questions from their academic documents.

Users can upload **PDF, DOCX, or PPTX** files and ask questions about the content. The system finds relevant information and generates an AI-based answer with sources.

## Features

* Supports PDF, DOCX, and PPTX files
* Extracts and processes document content
* Retrieves relevant information
* Generates AI-based answers
* Displays relevant sources
* Simple Streamlit interface

## How It Works

1. Upload an academic document.
2. Enter the subject and topic.
3. Ask a question.
4. The system processes the document.
5. Relevant information is retrieved.
6. AI generates the answer.
7. Sources are displayed.

## Technologies Used

* Python
* Streamlit
* LangChain
* FAISS
* Google Gemini
* PyPDF
* python-docx
* python-pptx

## Project Modules

* **Document Processing** – Handles PDF, DOCX, and PPTX files.
* **RAG Pipeline** – Retrieves relevant document information.
* **Vector Store** – Stores and searches document embeddings.
* **LLM** – Generates answers using AI.
* **Streamlit UI** – Provides the user interface.
